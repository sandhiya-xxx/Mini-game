#  Throne Lore Master

An interactive, data-driven companion app and wiki designed for gamers to explore deep universe lore, faction histories, and legendary character profiles. 

##  Features
* **Dynamic Lore Codex**: Fetches and displays lore profiles automatically from a centralized database.
* **Character Roster**: Highlights factions, roles, and backgrounds of key figures.
* **Clean Gaming UI**: Dark-themed, mobile-responsive dashboard designed for seamless immersion.

##  Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6)
* **Database**: JSON (Structured data format)
* **Version Control**: Git & GitHub

##  Project Structure
* `lore.json` - Centralized repository containing all raw gaming lore data.
* `index.html` - The frontend application that parses data and displays the user interface.
* `README.md` - Documentation and presentation hub for the challenge judges.
